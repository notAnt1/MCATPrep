# Start here: MCAT topic map

Version 1.0.0 | October 9, 2026

Start with `MCAT_Topic_Map.md` for the complete selectable list. It covers all four sections using expandable groups and topics. The 128 main topics are the default performance cells; 525 children are optional drilldowns. The 938 scope concepts are search/coverage detail, not a flat menu.

For website use, import `MCAT_Topic_Map.json`. Read `Question_Tagging_and_Heatmap.md` before classifying questions or calculating performance. Candidate categories are not automatic item tags. Preserve IDs across labels and versions. Use CARS reading tasks for performance and passage disciplines only as context filters.

`MCAT_Topic_Map.csv` supports spreadsheet review. `AAMC_Category_Crosswalk.csv` contains the official-category destinations and source page references. `Coverage_Review.md` and `Structural_Validation.json` explain executed reviews, corrections, and limitations.

This is an AAMC-grounded proposed product taxonomy, not an AAMC endorsement or a completed website. Existing practice questions have not been retagged. Learner usability and performance thresholds need validation. Official source links are included; no official practice-question copies or private data are packaged.
